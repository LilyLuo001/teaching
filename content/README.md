# Content — production packages

One file per unit from `curriculum/shipping_list.md`, named by unit code.
Publishing order is in `curriculum/publishing_order.md`.

Each package contains everything needed to film without further research:

| Section | What it is |
|---|---|
| **Evidence** | The examiner statements this unit exists to fix, with board, series, paper and page. Every unit must have at least one. No unit ships on a hunch. |
| **The one takeaway** | A single sentence. If the viewer remembers nothing else, this. |
| **Beats** | Timed blocks to 2:30–3:00. Keeps the edit honest. |
| **Script** | 400–450 words, spoken register. Read it aloud; if a sentence needs a second pass to parse, rewrite it. |
| **On-screen text** | What appears, and when. Deliberately sparse — text competes with narration. |
| **Diagram brief** | Enough for an illustrator or a slide deck. States what must be visible, not how to draw it. |
| **CTA** | Which diagnostic, and the exact words. |
| **Metadata** | Title options, thumbnail, description, tags. |

## Two rules that are not negotiable

**1. No verbatim exam-board text on screen beyond short attributed quotation.**
Past papers, mark schemes and examiner reports are the boards' copyright. Short
quotation for criticism and review is normal practice, but it must be *short*,
*attributed on screen*, and used to make a point about the mistake — never as a
substitute for original explanation. Never reproduce a question, a mark scheme,
or an extended passage. Sources came partly from an unlicensed mirror; that
makes the local files a research input, not publishable material.

**2. No invented statistics.** Not in the script, not in the thumbnail, not in
the description. The corpus supports statements like "four exam boards name this
confusion in their own reports" because that is countable and cited. It does not
support "70% of students get this wrong", because no board publishes per-error
failure rates. See `research/README.md`. AP scoring statistics are the single
exception — those are real published means, and they are quoted unmodified.
